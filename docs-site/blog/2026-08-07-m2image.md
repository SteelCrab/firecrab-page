Firecrab에 **M2Image** 기능이 추가되었습니다. M2Image는 M2를 생성할 때 사용하는 Firecracker용 VM 템플릿입니다.

{/* truncate */}

## M2Image란?

M2Image는 VM을 부팅하는 데 필요한 커널, rootfs, initramfs와 부팅 설정을 함께 담은 이미지입니다.

M2를 생성할 때 원하는 M2Image를 선택하면, Firecrab이 이를 기반으로 VM 전용 디스크를 준비하고 Firecracker microVM을 실행합니다.

## 왜 M2Image가 필요한가요?

Firecracker는 일반 배포판의 기본 이미지가 아닌, Firecracker 실행 환경에 맞게 구성된 커널과 rootfs가 필요합니다.

M2Image는 Alpine, Ubuntu, Rocky 같은 배포판의 공식 소스를 바탕으로 Firecrab에 맞는 형식으로 구성됩니다. 따라서 VM을 만들 때마다 운영체제를 처음부터 설치하지 않고, 준비된 템플릿을 빠르게 사용할 수 있습니다.

## 어떻게 동작하나요?

M2Image는 패키지 형태로 준비되고, Firecrab에 가져오면 사용할 수 있는 템플릿으로 등록됩니다.

M2를 시작할 때 Firecrab은 선택한 M2Image의 rootfs를 복사해 VM 전용 디스크를 만들고, VM별 설정을 적용합니다. 원본 M2Image는 변경되지 않으므로 여러 M2가 같은 이미지를 기반으로 생성될 수 있습니다.

## 사용 방법

1. 대시보드의 **이미지** 메뉴에서 사용할 M2Image를 설치하거나 부트스트랩합니다.
2. 준비된 M2Image를 Firecrab에 가져와 등록합니다.
3. M2 생성 시 원하는 M2Image를 선택합니다.
4. M2를 시작해 해당 이미지 기반의 microVM을 실행합니다.
