FireCrab의 문서와 개발 기록을 남길 공간을 열었습니다. 랜딩 페이지와 같은 도메인에서
`/docs`와 `/blog` 두 경로로 서비스합니다.

{/* truncate */}

## 두 공간의 역할

**[문서 `/docs`](/docs)** — FireCrab을 실제로 띄우고 운영하는 데 필요한 내용을 다룹니다.

- 설치 가이드: 요구 사항, Firecracker 준비, FireCrab 실행
- 설정 가이드: 자원 설정, 네트워크, 이미지 템플릿, 폐쇄망 환경 구성
- REST API 레퍼런스

**[블로그 `/blog`](/blog)** — 개발 기록을 남깁니다.

- 설계 결정과 그 이유
- Firecracker 연동 과정에서 부딪힌 문제와 해결 과정
- 릴리스 노트

## 시작하는 법

FireCrab은 아직 개발 초기 단계입니다. 지금은 VM 구성 레코드를 로컬 REST API로
생성·조회하는 수준까지 구현되어 있고, 실제 microVM 실행 연동은 진행 중입니다.
현재 범위와 로드맵은 [소개 문서](/docs)에 정리해 두었습니다.

설치·설정 가이드는 실행 연동이 안정화되는 대로 순차적으로 채워 나갑니다.
