We have opened a home for FireCrab documentation and development notes. Both live on the same
domain as the landing page, under `/en/docs` and `/en/blog`.

{/* truncate */}

## What each section is for

**[Documentation `/en/docs`](/en/docs)** — Everything needed to run and operate FireCrab.

- Installation: requirements, Firecracker preparation, and running FireCrab
- Configuration: resources, networks, image templates, and air-gapped environments
- REST API reference

**[Blog `/en/blog`](/en/blog)** — Notes from development.

- Design decisions and their rationale
- Problems encountered while integrating Firecracker and how they were solved
- Release notes

## Getting started

FireCrab is still in early development. It currently supports creating and reading VM configuration
records through a local REST API, while integration with actual microVM execution is in progress.
The current scope and roadmap are available in the [introduction](/en/docs).

Installation and configuration guides will be added as the execution integration stabilizes.
