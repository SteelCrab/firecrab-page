FireCrab now includes **M2Image**. An M2Image is a Firecracker VM template used to create an M2.

{/* truncate */}

## What is M2Image?

An M2Image contains the kernel, rootfs, initramfs, and boot configuration required to boot a VM.

When you select an M2Image while creating an M2, FireCrab prepares a dedicated VM disk from that
image and launches the Firecracker microVM.

## Why is M2Image needed?

Firecracker needs a kernel and rootfs prepared for its execution environment rather than an
unmodified default distribution image.

M2Image builds FireCrab-compatible images from official distribution sources such as Alpine,
Ubuntu, and Rocky. You can therefore reuse prepared templates instead of installing the operating
system from scratch for every VM.

## How does it work?

An M2Image is prepared as a package and registered as an available template when imported into
FireCrab.

When an M2 starts, FireCrab copies the selected M2Image rootfs to create a dedicated VM disk and
applies the VM-specific configuration. The original M2Image remains unchanged, so multiple M2s can
be created from the same image.

## How to use it

1. In the dashboard, open **Images** and install or bootstrap the M2Image you want to use.
2. Import and register the prepared M2Image in FireCrab.
3. Select the M2Image when creating an M2.
4. Start the M2 to run a microVM based on that image.
