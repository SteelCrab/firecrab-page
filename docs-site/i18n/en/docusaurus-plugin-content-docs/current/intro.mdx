# Introducing FireCrab

FireCrab is an open-source project for creating and managing [Firecracker](https://firecracker-microvm.github.io/)-based
microVMs from a web dashboard. It aims to be lighter than conventional VM platforms and practical
to operate on a single server, on premises, or in an air-gapped environment.

:::info[Current status]

FireCrab is in early development, but as of v0.3.0 it supports **M2Image installation and OCI image
import, MicroNetwork (IPv4 and IPv6) and MicroStorage, MicroVM create/start/stop, serial consoles and
key-based SSH, Shell provisioning, port forwarding, guest resource metrics, and the `firecrab` CLI**.
On Linux it runs directly on the host; on macOS (Apple silicon) and Windows it runs inside a managed
Debian VM created by microManager. Windows is still a Preview: MicroVMs cannot start on WSL2 yet.
Multi-host operation, high availability, and user authentication and authorization are not available yet.

:::

## What it solves

Conventional virtualization platforms are often much heavier than what is needed to run a single
microVM. FireCrab focuses exclusively on Firecracker and pursues three goals:

- **Lightweight operations** — Manage Firecracker without an entire hypervisor stack
- **Web-based management** — Inspect resource settings, status, consoles, and logs in a browser
- **Self-hosting** — Operate inside a private network without depending on an external service

## Components

| Component | Role | Status |
| --- | --- | --- |
| Web Dashboard | Manages MicroVMs, images, kernels, networks, storage, Shells, the host, and consoles | Implemented and improving |
| REST API | Manages resources and the MicroVM lifecycle | Implemented and improving |
| `firecrab` CLI | A REST API client for Linux, macOS, and Windows, plus host checks and updates | Implemented |
| Network Helper | Applies bridges, DHCP, NAT, firewall rules, and port forwarding | Implemented |
| M2Image | Prepares kernels and root filesystems through MicroRegistry install, OCI import, or MicroBoot (API-only) | Implemented |
| microManager | Creates a managed Debian VM on macOS and Windows that runs the same FireCrab | Implemented on macOS · Preview on Windows |

## Roadmap

**MVP scope**

- Snapshots, user authentication and authorization, and deployment history
- Recovery and backup workflows and a more advanced operations dashboard

**Later expansion**

- Multi-host operation, scheduling, and high availability
- Terraform provider, air-gapped packaging, and a template marketplace
