# FireCrab 소개

FireCrab은 [Firecracker](https://firecracker-microvm.github.io/) 기반 MicroVM을 웹 대시보드에서
생성·관리하는 것을 목표로 하는 오픈소스 프로젝트입니다. 기존 VM 플랫폼보다 가볍게,
단일 서버·온프레미스·폐쇄망 환경에서도 운영할 수 있는 구조를 지향합니다.

:::info[현재 진행 상태]

FireCrab은 개발 초기 단계이지만, v0.3.0 기준으로 **M2Image 설치와 OCI 이미지 가져오기, MicroNetwork(IPv4·IPv6)·MicroStorage,
MicroVM 생성·실행·중지, 시리얼 콘솔과 키 기반 SSH, Shell 프로비저닝, 포트 포워딩, 게스트 리소스 관측, `firecrab` CLI**를 지원합니다.
Linux에서는 호스트에서 직접 실행하고, macOS(Apple silicon)와 Windows에서는 microManager가 만드는 관리용 Debian VM에서 실행합니다.
Windows는 아직 WSL2에서 MicroVM을 시작하지 못하는 Preview 상태입니다.
멀티 호스트, 고가용성, 사용자 인증·권한은 아직 제공하지 않습니다.

:::

## 무엇을 해결하나

기존 가상화 플랫폼은 MicroVM 하나를 띄우는 데 필요한 것보다 훨씬 무겁습니다.
FireCrab은 Firecracker 한 가지에 집중해서 다음을 노립니다.

- **가벼운 운영** — 하이퍼바이저 스택 전체가 아니라 Firecracker만 다룹니다
- **웹 기반 관리** — 자원 설정, 상태, 콘솔, 로그를 브라우저에서 확인합니다
- **자체 호스팅** — 외부 서비스 의존 없이 내부망에서 그대로 운영합니다

## 구성 요소

| 구성 요소 | 역할 | 상태 |
| --- | --- | --- |
| Web Dashboard | MicroVM·이미지·커널·네트워크·스토리지·Shell·호스트·콘솔 관리 | 구현·개선 중 |
| REST API | 리소스와 MicroVM 생명주기 관리 | 구현·개선 중 |
| `firecrab` CLI | Linux·macOS·Windows에서 REST API를 호출하는 클라이언트, 호스트 점검·업데이트 | 구현 |
| Network Helper | bridge, DHCP, NAT, 방화벽과 포트 포워딩 적용 | 구현 |
| M2Image | MicroRegistry 설치, OCI 가져오기, MicroBoot(API 전용)로 커널·RootFS 준비 | 구현 |
| microManager | macOS·Windows에서 관리용 Debian VM을 만들어 같은 FireCrab 실행 | macOS 구현 · Windows Preview |

## 로드맵

**MVP 범위**

- Snapshot, 사용자 인증·권한, 배포 이력 관리
- 복구·백업 흐름과 운영 대시보드 고도화

**이후 확장**

- Multi Host, Scheduling, 고가용성
- Terraform Provider, 폐쇄망 패키징, Template Marketplace
