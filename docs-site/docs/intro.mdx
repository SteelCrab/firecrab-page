# FireCrab 소개

FireCrab은 [Firecracker](https://firecracker-microvm.github.io/) 기반 MicroVM을 웹 대시보드에서
생성·관리하는 것을 목표로 하는 오픈소스 프로젝트입니다. 기존 VM 플랫폼보다 가볍게,
단일 서버·온프레미스·폐쇄망 환경에서도 운영할 수 있는 구조를 지향합니다.

:::info[현재 진행 상태]

FireCrab은 개발 초기 단계입니다. 지금은 **VM 구성 레코드를 로컬 REST API로 생성·조회**하는
수준까지 구현되어 있으며, 실제 microVM 실행 연동은 진행 중입니다.
문서에 적힌 내용 중 로드맵 항목은 `로드맵` 표시로 구분합니다.

:::

## 무엇을 해결하나

기존 가상화 플랫폼은 MicroVM 하나를 띄우는 데 필요한 것보다 훨씬 무겁습니다.
FireCrab은 Firecracker 한 가지에 집중해서 다음을 노립니다.

- **가벼운 운영** — 하이퍼바이저 스택 전체가 아니라 Firecracker만 다룹니다
- **웹 기반 관리** — 자원 설정, 상태, 콘솔, 로그를 브라우저에서 확인합니다
- **자체 호스팅** — 외부 서비스 의존 없이 내부망에서 그대로 운영합니다

## 구성 요소

| 구성 요소 | 역할 | 상태 |
| --- | --- | --- |
| Web Dashboard | MicroVM 생성·조회 UI | 구현 중 |
| REST API | VM 구성 레코드 관리 | 일부 구현 |
| Host Agent | 호스트에서 Firecracker 프로세스 제어 | 로드맵 |
| Image Template | RootFS·커널 이미지 템플릿 | 로드맵 |

## 로드맵

**MVP 범위**

- Template 관리, Snapshot, Monitoring
- 사용자 / 권한 관리, Host Agent, 배포 이력 관리

**이후 확장**

- Multi Host, Scheduling, Template Marketplace
- Terraform Provider, 폐쇄망 패키징, 운영 대시보드 고도화
